Репозиторий INI Color Editor
Описание
INI Color Editor – это набор консольных утилит на 8 языках программирования для просмотра и редактирования INI-файлов с подсветкой синтаксиса. Программа позволяет читать, изменять, добавлять и удалять секции и ключи, а также выводить содержимое файла с цветовым выделением секций, ключей, значений и комментариев.

Возможности
Просмотр INI-файла с подсветкой синтаксиса в терминале (ANSI-цвета):

Секции – ярко-синий/голубой

Ключи – зелёный

Значения – жёлтый

Комментарии – серый

Равно и скобки – белый (по умолчанию)

Редактирование – изменение значения ключа, добавление новой секции или ключа, удаление секции или ключа.

Поиск – поиск по ключам, значениям или комментариям.

Сохранение – запись изменений обратно в файл или в новый файл.

Интерактивный режим – пошаговое редактирование с подсказками.

Пакетный режим – выполнение команд через аргументы командной строки (например, --set section.key=value).

Цветовая схема – возможность переключения между светлой и тёмной темой.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (только стандартная библиотека)	python ini_editor.py [опции] [файл.ini]
JavaScript	Node.js 14+ (без внешних модулей)	node ini_editor.js [опции] [файл.ini]
TypeScript	Node.js + ts-node (только стандартные модули)	ts-node ini_editor.ts [опции] [файл.ini]
Go	Go 1.18+ (без внешних зависимостей)	go run ini_editor.go [опции] [файл.ini]
Java	JDK 11+ (без внешних библиотек)	javac IniEditor.java && java IniEditor [опции] [файл.ini]
C#	.NET SDK 6.0+ (или csc)	csc IniEditor.cs && IniEditor.exe [опции] [файл.ini]
PHP	PHP 8.0+ (только стандартные функции)	php ini_editor.php [опции] [файл.ini]
Ruby	Ruby 2.7+ (без гемов)	ruby ini_editor.rb [опции] [файл.ini]
Использование
text
ini_editor [опции] [файл.ini]
Если файл не указан, программа переходит в интерактивный режим (запрос файла).

Опции
Опция	Описание
-v, --view	Показать содержимое файла с подсветкой (по умолчанию).
-s, --set <ключ=значение>	Установить значение ключа (секция.ключ=значение).
-g, --get <ключ>	Показать значение ключа (секция.ключ).
-d, --delete <ключ>	Удалить ключ (секция.ключ).
-a, --add <секция>	Добавить новую секцию.
-r, --remove <секция>	Удалить секцию и все её ключи.
-o, --output <файл>	Сохранить результат в указанный файл (вместо перезаписи исходного).
--color	Включить цветной вывод (по умолчанию, если терминал поддерживает).
--no-color	Отключить цветной вывод.
--theme <light/dark>	Выбрать цветовую тему (по умолчанию dark).
-h, --help	Показать справку.
Примеры
bash
# Просмотр файла с подсветкой
python ini_editor.py config.ini

# Установить значение ключа
python ini_editor.py config.ini --set "database.host=localhost"

# Получить значение ключа
python ini_editor.py config.ini --get "database.port"

# Удалить ключ
python ini_editor.py config.ini --delete "database.password"

# Добавить секцию
python ini_editor.py config.ini --add "new_section"

# Удалить секцию
python ini_editor.py config.ini --remove "old_section"

# Сохранить в другой файл
python ini_editor.py config.ini --output config_new.ini --view
Формат INI
Программа поддерживает стандартный формат INI:

Секции обозначаются [section].

Ключи и значения разделяются знаком =.

Комментарии начинаются с ; или #.

Пустые строки игнорируются.

Пробелы вокруг ключей и значений обрезаются.

Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Парсинг INI-файла с учётом комментариев и пустых строк.

Цветной вывод с использованием ANSI-кодов.

Обработка ошибок (неверный формат, отсутствие файла).

Возможность работы в пакетном и интерактивном режимах.

Сохранение изменений с сохранением комментариев и структуры (в большинстве реализаций).
